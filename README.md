# SmartCC Spend Optimizer

Automatically fetches credit-card transaction alerts from Gmail, analyses your spending, and tells you exactly where you're leaving cashback on the table — and which new card would save you the most.

---

## Features

| Feature | Description |
|---------|-------------|
| **Email Parsing** | Reads debit alerts from HDFC, IDFC First, SBI, Axis, ICICI, Kotak |
| **Auto Categorisation** | 10 categories: Food & Dining, Online Shopping, Grocery, Fuel, etc. |
| **Channel Detection** | Classifies each transaction as online or offline |
| **Spend Dashboard** | Monthly trends, category breakdown, top merchants, per-card analytics |
| **Portfolio Optimizer** | Shows missed cashback per transaction and which owned card to use instead |
| **Card Recommender** | Ranks un-owned cards by estimated annual net benefit on your actual spend |

## Quick Start

### 1. Clone and install

```bash
git clone <repo-url>
cd smartcc_spend_optimizer
python -m venv .venv
.venv\Scripts\activate        # Windows
# source .venv/bin/activate   # macOS / Linux
pip install -r requirements.txt
```

### 2. Configure Gmail

1. Enable **2-Step Verification** in your Google Account.
2. Go to **Security → App Passwords**, create one for "Mail".
3. Copy `.env.example` → `.env` and fill in your Gmail address and the 16-char app password.

```bash
cp .env.example .env
```

### 3. Configure your cards

Edit [config.yaml](config.yaml) and add each credit card you own:

```yaml
cards:
  - bank: hdfc
    last_four: "9930"       # last 4 digits as they appear in alert emails
    name: "HDFC Millennia"  # friendly name shown in the dashboard
    catalog_id: hdfc_millennia  # links to cashback rates in backend/card_catalog.py
```

**Available `catalog_id` values:**

| catalog_id | Card |
|------------|------|
| `hdfc_millennia` | HDFC Millennia |
| `hdfc_cashback` | HDFC Cashback Card |
| `hdfc_swiggy` | HDFC Swiggy Credit Card |
| `icici_amazon_pay` | ICICI Amazon Pay |
| `axis_ace` | Axis ACE |
| `axis_flipkart` | Axis Flipkart |
| `sbi_cashback` | SBI Cashback Card |
| `sbi_simply_click` | SBI SimplyCLICK |
| `idfc_first_wealth` | IDFC FIRST Wealth |
| `amex_mrcc` | Amex Membership Rewards CC |

### 4. Run the dashboard

```bash
streamlit run frontend/dashboard.py
```

Open **http://localhost:8501** in your browser.  
Click **🔄 Run Parser** in the sidebar to fetch emails and populate data.

Or run the parser standalone:

```bash
python backend/email_reader.py --days 90
```

## Savings Advisor Logic

### Portfolio Optimizer
For every purchase transaction in the selected period:
- **Actual rate** = cashback % from the card you used (looked up from `backend/card_catalog.py`)
- **Optimal rate** = best cashback % available across all your owned cards for that category + channel
- **Missed ₹** = `amount × (optimal_rate − actual_rate) / 100`

### Card Recommender
For each card you don't own:
1. Calculate annual cashback on your current spend (by category × channel × cashback rate × annualisation factor)
2. Apply the card's monthly cap if applicable
3. Subtract annual fee → **Net annual benefit**
4. Rank all cards by net benefit and surface top 3

## Adding More Cards to the Catalog

Edit [backend/card_catalog.py](backend/card_catalog.py) and add a new entry:

```python
"my_new_card": {
    "display_name": "My New Card",
    "issuer": "Bank Name",
    "annual_fee": 500,
    "fee_waiver_spend": 100000,
    "cashback": {           # online rates per category
        "Online Shopping": 3.0,
        "Food & Dining":   2.0,
        "Other":           1.0,    # fallback
    },
    "offline_cashback": {   # None = same rates for offline
        "_default": 1.0,
    },
    "monthly_cashback_cap": 2000,  # None for no cap
    "notes": "Short benefit summary shown in dashboard",
    "best_for": ["Online Shopping", "Food & Dining"],
    "color": "#HEXCODE",
},
```

## Privacy & Security

- Credentials are stored only in `.env` (excluded from git).
- The app reads emails but **never stores** raw email content — only extracted transaction fields.
- All data stays local; nothing is uploaded to any external service.

## Troubleshooting

| Problem | Fix |
|---------|-----|
| Parser returns 0 transactions | Check sender addresses in `backend/email_reader.py → BANK_PATTERNS` |
| Merchant shows "Unknown" | Add `print(body)` inside `_parse_transaction` to inspect the raw text, then add a pattern to the `merchant` list |
| `lxml` not found | `pip install lxml` or edit `email_reader.py` to replace `"lxml"` with `"html.parser"` |
| Gmail login fails | Re-generate your App Password; enable IMAP in Gmail Settings |
| `ModuleNotFoundError: backend` | Run commands from the **project root** (where `config.yaml` lives), not from inside a subfolder |
